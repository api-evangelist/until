# Until

Until (Until Labs) is a biotechnology company building the medical infrastructure to pause biological time. It is developing reversible cryopreservation systems for human organs — starting with organ-scale reversible cryopreservation to solve the donor-organ procurement and matching problem, and methodically scaling toward whole-body preservation.

Founded by Laura Deming and Hunter Davis. Backed by Founders Fund. Raised $100M+ to date.
